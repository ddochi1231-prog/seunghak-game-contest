# 승학초 게임 대회 웹앱

엔트리(.ent) 게임 10개를 웹에서 실행하고, 게임별 실시간 순위와 후기를 제공하는 웹앱입니다. 기획은 [PRD.md](PRD.md) 참고.

## 구조
- `web/` 정적 웹앱 (화면 + 엔트리 런타임 + 게임 파일). 어디든 정적 호스팅 가능
- `apps-script/Code.gs` 구글시트 저장소 API (순위·후기·로그인)
- `tools/build_games.py` 루트의 .ent → `web/games/` 변환
- `tools/serve.py` 로컬 테스트 서버

## 내 컴퓨터에서 연습해 보기 (구글시트 없이)
```bash
python tools/serve.py 8001 --demo
```
브라우저에서 http://localhost:8001 — 연습 모드로 동작(구글시트에 아무것도 쓰지 않고 기록은 이 브라우저에만 저장). 연습 모드 관리자 암호: `admin`. (`--demo` 없이 실행하면 config.js의 실제 구글시트에 연결됩니다.)

## 실제 운영 (구글시트 연결)
1. 새 구글 시트를 만들고 **확장 프로그램 → Apps Script**에 `apps-script/Code.gs`를 붙여넣기
2. `setup` 함수를 한 번 실행(권한 허용) → `settings` 탭의 `adminPassword`를 원하는 암호로 변경
3. **배포 → 새 배포 → 웹 앱**(실행: 나, 액세스: 모든 사용자) → URL(`…/exec`) 복사
4. `web/config.js`의 `apiUrl`에 URL 붙여넣기
5. `web/` 폴더를 GitHub Pages / Netlify 등에 올려 학생들에게 주소 공유 (엔트리 런타임이 약 18MB라 Apps Script 자체 호스팅은 불가)

## 게임 정보·그림
- 게임 소개·조작법·순위 방식은 '게임 안내' PDF 내용을 `tools/build_games.py`의 `INFO`에 옮겨 둔 것입니다. 수정 후 `python tools/build_games.py`
- 카드 그림은 PDF에서 `python tools/extract_pdf_images.py`로 `web/img/`에 추출 (PDF가 바뀌면 다시 실행)
- 순위 방식: 🏆 점수 대결(동전 모으기·바나나 구하기·표적 클릭) / ⏱ 빠른 클리어(공과 별·달리기 경주) / ⭐ 별점 평가(나머지 5개)
- **순위 방식을 바꾸면 `Code.gs`의 `GAME_RULES`를 고쳐서 Apps Script를 다시 배포해야 합니다.**

## 게임 설정 바꾸기
- 순위 기준·점수 변수: `tools/build_games.py`의 `SCORE_VAR_OVERRIDE`, 실행 후 `web/games/manifest.json`에서 `title`, `rankType`(score_high / time_low / manual_high) 수정
- **manifest의 rankType을 바꾸면 `Code.gs`의 `GAME_RULES`도 같이 바꿔야 합니다.**
- .ent 파일을 바꾼 뒤에는 `python tools/build_games.py` 재실행 (manifest가 새로 만들어지니 수정 내용은 다시 반영)

## 이번 버전의 화면과 기능
- 로그인 전 10개 게임 둘러보기, 학급 필터, 게임·제작자 검색, 후기·별점 정렬
- 게임별 순위, 내 도전 기록, 참가 안내
- 시작·다시 시작·멈춤·전체화면, 점수 및 클리어 시간 기록
- 별점 후기, 본인 후기 수정·삭제, 이름 마스킹, 금칙어 검사
- 교사 화면에서 대회 열기·닫기, 기록 초기화·삭제, 후기 삭제
- 교사 CSV 내보내기: 각 게임 상위 10명 기록과 표시된 후기

## 확인 결과와 실제 대회 준비
10개 프로젝트의 캔버스 로딩을 브라우저에서 확인했습니다. 바나나 구하기의 시작 동작도 확인했습니다. 로그인 이름 불일치, 최고 점수·최단 시간, 후기 저장·금칙어, 대회 종료 잠금 기능 검사를 통과했습니다.

게임별 모든 장면과 클리어 조건, 사운드, 태블릿 터치 조작은 제작 학생과 함께 대회 전 확인해 주세요. 일부 게임에서 엔트리 사운드 로딩 오류가 관찰되어 소리 호환성은 미확인 상태입니다. 점수 변수가 없는 게임은 현재 클리어 시간 방식이며 선생님이 게임 특성에 맞게 조정해야 합니다.

현재는 구글시트 URL이 없어 연습 모드입니다. 서로 다른 기기에서 공동 순위를 사용하려면 위의 실제 운영 연결 및 정적 호스팅 절차가 필요합니다.
